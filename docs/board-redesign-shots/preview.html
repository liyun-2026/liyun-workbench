● 已上线 · VoxOS 5.24 —— 两款随时切换（右下角浮钮 / _boardMode 本机记住），以下为生产真机成片

看板端重设计 · 两款定稿

针对「5.23 两款看不出区别」的批评返工：这一轮把底色（米白 vs 深蓝）、信息密度（一张海报 vs 一面数据墙）、骨架（单卡居中 vs 三列面板）全部拉开，远看一眼就是两块不同的屏。以下均为 VoxOS 5.24 生产版 1920×1080 真机渲染：真时钟（秒在走）、真 60 秒换码倒计时（最后十秒转红催换）、真 QRLib 二维码（编动态码本身）、真种子数据（40 人口径：应到 37 / 实到 30 / 迟到 4 / 请假 3 / 未到 7）。
款式 1 · 签到立牌（SIGNAGE） 「一张会动的海报」——米白暖纸浅底，全屏只服务扫码：中央超大白卡（巨型码 ≥420px + 衬线特大 6 位数字 + 金条换码倒计时），顶带博艺蓝徽 + 衬线大时钟 + 日期节次（当前节次实时）；底部金线之上一条考勤明细带：五数全上（应到 37 · 实到 30 · 迟到 4 · 请假 3 · 未到 7，按语义金/赭/蓝/红着色）+ 小字名单「未到 学员34 … 等 7 人 · 请假 学员31、学员32、学员33」，仍保持海报克制、不与主卡抢视觉；金线下方校训 + 班级落款。课程 / 量化 / 通知一概不上屏。
款式 2 · 信息中枢（DASHBOARD） 「办公室数据墙」——深蓝底多面板仪表盘，信息密度拉满，不承担扫码（打卡板块整块移除）、也不上内部管理内容（工单板块整块移除）：左列今日课程全节次时间轴（当前节金高亮「进行中」徽、明日预览置灰）；中列今日考勤四大数 2×2 大格（应到 / 实到 / 迟到 / 请假）+「还没到名单」红点胶囊；右列班级量化前 5 + 最新通知 3 条；底部通知跑马灯 + 校训金线。全屏只保留学生可见信息，与款式 1 形成「远看海报 / 近看报表」的强对比。
切换 · 右下角浮钮（hover 浮出） 鼠标移到右下角浮出「切换布局 · 当前 信息中枢」+「退出 (Esc)」：点一下即切另一款（免刷新、即时生效），本机记住选择（_boardMode），下次打开落在上次的模式；Esc 随时直接退出看板。
两款式差异一句话：款式 1 把一切让给那枚码（米白 / 单卡 / 零信息噪音），款式 2 把一切摆上墙（深蓝 / 三列 / 全量数据）——同一块屏，两种人格。
共同底座：数据全走 Board 现成链路（Auth.call('code') 60s 动态码 / collect 口径 / schedule+periods / quant_log / tickets），零新增接口；WakeLock + Esc 退出保留。
