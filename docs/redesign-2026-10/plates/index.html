砺蕴教务系统 · Web 端视觉升级 —— 3 版风格稿对照

三版都渲染了同一个「今日」页，内容（导航项 / 倒计时 / 今日速览 / 每日新闻）完全一致，只有令牌与气质不同 —— 请用眼睛选，不要读表格选。每份稿都带：手机预览开关、浅色 / 深色开关、以及一条把色板 / 字号 / 间距 / 圆角直接画出来的「令牌条」。
