## 1. 标杆研究：究竟去开源世界学什么

用户要求「去看 github 上已经开源的优秀网站代码，学习他们的优点长处」。下面每个案例都落到**一条可复用、可落到代码级的具体手法**，并标注**为什么不照搬**——后台管理类系统的约束（信息密度高、复访率高、任务导向）与营销落地页（一次性、讲故事、可牺牲效率换惊艳）是两套价值排序。

### 1.1 可直接抄的 6 个案例

| # | 仓库 / 站点 | 学到的具体手法（代码级） | 怎么用到砺蕴 |
|---|---|---|---|
| 1 | **argyleink/open-props**（GitHub，MIT，5.2k★） | 用一套开箱即用的 CSS 变量把「间距 / 字号 / 缓动 / 圆角 / 阴影」全部打平成 token，间距走 **4px 基准 × 6~8 档**，字号自带 `clamp()` 流体档 | 现系统间距只有 `--pad:18px` / `--gap:12px` 两个值（L110-111）。照搬"4px 基准 + 6~8 档"，把卡片内边距、区块间距、元素间距全部走刻度；缓动从单一 `--ease`（L113）扩成 2~3 条曲线 |
| 2 | **shadcn-ui/ui + radix-ui/colors**（MIT） | **语义 token 分层**：`background/foreground/card/muted/border/ring/radius` 只描述"用途"，不描述"颜色"；色阶每步有固定用途（1-2 底、3-5 组件、6-8 边框、9-10 实心、11-12 文字）；`radius` 用 `calc(var(--radius) * n)` 派生 | 把"跨端恒定的语义色"（成功/警示/危险/信息）从"端口 accent"里**解耦**出来；`calc(var(--radius) - 6px)`（L302/309/323 已有雏形）统一成正则派生。**不必上 12 步色阶**，一色 3~4 步足够 |
| 3 | **vercel/geist-font**（GitHub，OFL）+ Vercel Geist 设计系统 | 字重**克制**（400–510 带宽，不用 bold 拉层级）；**Mono 专门服务数字/ID/时间/金额**；"层级先靠排版，颜色和装饰靠后" | 现只有 `.num/.hero` 带 `tabular-nums`（L293），列表/统计里的数字会跳列。把 `tabular-nums` 提升到全局或统一 `.num`，时间/学号/分数走 `--mono`（L112 已有）；字重收敛为 400/500/600 三档 |
| 4 | **tufte-dataink**（Edward Tufte 范式，《The Visual Display of Quantitative Information》） | **每个像素都要有理由**：去掉图表垃圾、无边框盒、直接给数据端点标注、small multiples；颜色只用于编码含义，不用于装饰 | 系统的看板端（`.bd-*`，L1260+）已是这个思路（不用卡片、细线分栏、宋体标头）。把这条**固化成"数据页规范"**，推广到量化页、考勤统计页 |
| 5 | **Stripe Press**（press.stripe.com，opendesign 有完整 token 包） | 暖纸底 `#F1ECDE`（**绝不用正白**）+ 衬线标题 + 间距 `4/8/16/24/32/48/96` + 圆角 `0` + 慢动效（1–2s 交叉淡入）+ 每章单一"烫金色" | 直接支撑**方向 C**；同时回答"为什么不该用 `#fff` 底"——现 `--card:#ffffff`（L76）在暖底 `#f6f5f2` 上其实已经微微发冷 |
| 6 | **alphagov/govuk-frontend**（GitHub，MIT，GOV.UK 设计系统） | **焦点环规范化**（黄底 + 黑粗边，满足 WCAG 2.2 AA，设计系统 5.12 专为自建表单新增 focus mixin）；**错误摘要置顶 + 焦点管理**；表单按"用户在压力下填表"来设计 | 现 `input:focus` 只改 `border-color:var(--accent)`（L306），**键盘用户看不见焦点**。照搬"高对比焦点环（`:focus-visible`）+ 错误摘要置顶"，这是无障碍硬要求 |

### 1.2 只学思路、不照搬的 3 个案例（关键：说明为什么不适用）

| # | 仓库 / 站点 | 手法 | 为什么**不**照搬到砺蕴 |
|---|---|---|---|
| 7 | **adrianhajdin/award-winning-website**（Zentry 克隆，React+GSAP+Tailwind） | 滚动驱动动画、`clip-path` 几何转场、视频叙事、3D hover | 这是**营销落地页**范式：滚动叙事、全屏视频、大片视差，对后台管理是**分心源**。只借一条：滚动渐显改用原生 `animation-timeline: view()`（跑在合成线程，零 JS），并给不支持浏览器**静态兜底**（元素默认就是终态） |
| 8 | **brunosimon/folio-2019**（GitHub，MIT，Awwwards Site of the **Year 2020**，Three.js + Rapier + Howler） | "作品集本身就是能力的证明"、交互即导航、成就/地图/画质切换等超配细节、第 0 帧就有一辆车（响应感） | 3D 世界、游戏化导航、WebAudio 对"一天开十次的教务工具"是**纯负担**。只学一条：**第 0 帧就要稳定**——对应现系统的开屏层（L128+ 刻意不做入场动画、只留持续运动 + 恒定相位）做得完全正确，应保留并推广到切页 |
| 9 | **Linear / Vercel 设计系统**（DESIGN.md 范式） | hairline 1px 边框代替投影、surface ladder（canvas → surface-1..4）、accent 用量 <5%、display 负字距、radius **不超过 16** | 卡片"细线代投影"（L284 注释）方向正确，可引入 **surface ladder** 概念给卡片分档；但 Linear 的纯暗色、键盘快捷键文化、mono chip 对**非技术用户（教务/老师）不落**，暗色只作为可选主题 |

### 1.3 代码级「可直接抄」手法清单（把这些写成规范）

| 手法 | 现状 | 建议 |
|---|---|---|
| `clamp()` 流体字号/间距 | 用媒体查询改 `:root` 字号（L915/950）做 3 次跳变 | 用 `clamp()` 让字号/内边距连续变化，少一半断点 |
| 4/8 基准 spacing scale | 2 个值 | 6~8 档 token |
| `color-mix()` / `oklch()` | 每个 hover/selected 手写第二套 hex（如 `.chip-no` L326、tier 五色 L1008-1012） | 用 `color-mix(in oklch, …)` 从主色派生 hover/disabled，减少硬编码 |
| `@layer` 收样式 | 全站无 `@layer`，特异性靠 `!important` 和"写在后面取胜"（见 L1125 注释） | 引入 `@layer reset, tokens, base, components, utilities`，消灭"必须写在上面那条之后"的坑 |
| `content-visibility:auto` | 无 | 给长列表（名册、学生账号 L2548）降首屏渲染成本 |
| `text-wrap:balance` / `pretty` | 无 | 标题用 `balance`，正文用 `pretty`（中文长句防孤字） |
| 滚动驱动动画 `animation-timeline: view()` | 用 `nth-child` 错开 `rise` 入场（L375-381） | 用原生 scroll-driven + 静态兜底；**弱化**每次切页整页上浮 |
| View Transitions | 无 | 用于"列表→详情"或端口切换的转场（`view-transition-name`），带 `prefers-reduced-motion` 关闭 |
| `:focus-visible` 焦点环 | 无（L306 只改边框色） | 规范化高对比焦点环（学 GOV.UK） |
| `prefers-reduced-motion` | **已有且做得对**（L211、L388） | 保留 |
| 骨架屏 / 首帧稳定 | **已有开屏层且做得对**（L128+） | 保留 |
| 图片防跳版 | `brand-lock` 用 `aspect-ratio`（L1098） | 推广到所有图：`srcset` + `aspect-ratio` + 固定占位 |
| 容器查询 `@container` | 全部靠全局断点 | 卡片自适应用小容器查询，减少全局断点数量 |
| `tabular-nums` | 仅 `.num/.hero`（L293） | 全局或统一 `.num` |
| `:has()` 状态化 | 无 | 如 `.card:has(.empty){…}` 自动降密度，避免空卡占大位 |
| 按钮 `:active scale(.97)` | **已有**（L384-385） | 保留（符合 Emil Kowalski 规范） |

> 参考：Emil Kowalski（Sonner / Vaul / animations.dev）的动效规范——ease-out 为默认、UI 动画 **<300ms**、只动 `transform/opacity`、动画可中断、尊重 reduced-motion。现系统方向已一致，主要是把 `transition:all`（L383）收窄成具体属性。

## 3. ⭐ 3 版视觉方向（本轮核心交付）

三版在**气质上真正拉开**：A 沿用暖金做极致精修（风险最低）；B 走冷静灰白单点缀（数据页最稳）；C 走编辑感大留白（文化厚度最强）。
所有方向都**保持单文件 `index.html` + 原生 CSS 变量，不引入构建**。

> 共同原则（三版通用）：不动 `prefers-reduced-motion` 兜底；不动开屏层恒定相位逻辑；不动端口换色机制本身（只动"取值"）；不动业务逻辑与 Store/路由。

## 4. 5 个高频页的信息架构与布局

> 骨架说明：**桌面** = 侧栏（236px）+ 内容区；**手机** = 顶栏 + 内容 + 底部胶囊标签栏（保留现有骨架，仅做令牌级调整）。

### 4.1 今日（`page-home`，路由 id `home`）—— "今天该做什么、还剩几天"

| 项 | 内容 |
|---|---|
| 用户来干什么 | 一眼看清：倒计时还剩几天、今天有什么课/事项、别人（学生）今天做了什么（打卡/请假） |
| 一眼必须看到 | **倒计时天数（最大数字）** + 今日速览（课/事项条数） |
| 信息优先级 | ① 倒计时（hero）② 今日速览 ③ 每日新闻 |
| 桌面骨架 | 顶部 hero 卡整宽（倒计时大数字 + 进度环）→ 下方两列：左「今日速览」，右「每日新闻」（限高滚动） |
| 手机骨架 | 竖排：hero 卡占第一屏 → 今日速览 → 新闻折叠（点击展开） |
| 插图/图形位 | 倒计时卡右侧：**进度环 / 日历图形**（可用纯 SVG 绘制，不必生成图）；空态插图 |

### 4.2 考勤（`page-att`）—— "给某班某时段点名，一键正常，导出"

| 项 | 内容 |
|---|---|
| 用户来干什么 | 快速点名：选班级/日期/时段 → 逐个标状态 → 一键全部正常 → 导出 |
| 一眼必须看到 | **应到/实到/异常 三个数** + 学生名单（可点） |
| 信息优先级 | ① 名单 + 状态操作（主）② 筛选器（日期/班/时段）③ 请假列表 + 导出（次级） |
| 桌面骨架 | 顶部一条筛选（日期 / 班级 / 时段 + 「管理时段」）；主区左列学生名单（可滚，主），右侧汇总数 + 请假 + 导出 |
| 手机骨架 | 竖排：筛选吸顶 → 汇总三个数（一排）→ 学生名单全宽 → 操作按钮（一键正常/复制小结）底部 sticky |
| 插图/图形位 | 汇总用**状态环/进度条**（SVG）；异常态用图标，不生成插图 |

### 4.3 名册（`page-roster`）—— "建班、加人、建号、看结构"

| 项 | 内容 |
|---|---|
| 用户来干什么 | 维护组织结构：建班 → 加学生 → 批量/单独建号 → 设班干部 |
| 一眼必须看到 | **班级列表 + 当前班学生数** |
| 信息优先级 | ① 班级 → 学生（主）② 批量建号 ③ 单独建号 / 班干部 / 周末班（次级） |
| 桌面骨架 | 复用现有 `.split`：左「班级列表」（236~288px），右「学生列表 + 操作」，建号卡在右栏下方；周末班等次级卡收进"更多"折叠 |
| 手机骨架 | 班级用**横向 chips 滑动**选择 → 学生列表全宽 → 建号入口收进底部"全部功能"抽屉 |
| 插图/图形位 | **空班级 / 空学生** 空态插图（需要生成）；无数据装饰图 |

### 4.4 作业（`page-homework`）—— "布置作业 + 检查完成"

| 项 | 内容 |
|---|---|
| 用户来干什么 | 两道主任务：① 布置作业给若干班 ② 按班/日期检查完成情况 |
| 一眼必须看到 | **今日检查的完成进度（已检/未检）** |

| 桌面骨架 | 左「今日检查」（选班+日期，勾选列表），右「布置作业」（班级多选 + 日期 + 文本域）；「作业列表」整宽置底 |

| 插图/图形位 | **不需要插图**（纯表单/列表型页，加图违反"拒绝无意义装饰"） |

### 4.5 设置（`page-settings`）—— "账号 / 数据 / 系统"

| 项 | 内容 |
|---|---|
| 用户来干什么 | 管理账号与同步、做数据备份/恢复、进高级（密钥/演示/健康/巡检） |
| 一眼必须看到 | **账号状态 + 数据备份（导出/恢复）** |
| 信息优先级 | ① 数据备份 ② 账号与同步 ③ 高级（换设备密钥 / 演示账号 / 系统健康 / 巡检 / 量化细则 / 看板入口） |
| 桌面骨架 | 分两段：**常用**（备份、账号）在上，**高级**（密钥/演示/健康/看板）在下；左侧可加锚点导航 |
| 手机骨架 | 竖排 + 分段标题（"常用" / "高级"），高级段默认折叠 |
| 插图/图形位 | **不需要插图**（设置页保持零装饰） |

## 5. 品牌配图清单

**原则**：只在"空态"和"品牌识别"两处用图；**数据页与表单页一律不用装饰图**（用户标准明确"拒绝无意义装饰"）。风格统一：单色/双色线描、与 `--line` / `--gold` 同系、**透明底、1.5px 线宽、无渐变、无 3D**，浅深两套。

| # | 图 | 用途 | 尺寸建议 | 风格要求 | 是否本轮必需 |
|---|---|---|---|---|---|
| 1 | 空态插图 × 6~8 | 无班级 / 无学生 / 无作业 / 无考勤记录 / 无新闻 / 无数据 / 无权限 | 480×360（@2x）透明 PNG 或 SVG | 线描，单色（`--line`）+ 一点金（`--gold`），无人物脸 | ✅ 必需 |
| 2 | 倒计时进度环 / 日历图形 | 「今日」hero 卡右侧 | 矢量（SVG） | 纯 SVG 绘制，不生成位图 | ✅ 建议 SVG |
