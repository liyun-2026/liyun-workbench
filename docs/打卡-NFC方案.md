# 砺蕴 · 打卡结合 NFC 方案

> 日期：2026-09-23　配套文档：`学生端综合方案-v2.md`（打卡总体设计）、`学生端建设方案.md`（板块清单）
> 一句话结论：**NFC 值得做，但它只能当打卡的「一种」到场证明，不能当唯一方式。**
> 安卓手机碰一下直接打卡成功；iPhone 走动态码/定位；两条路写进同一张考勤表，教务看不出区别。

---

## 一、先把最要命的事实摆出来：不是每部手机都能用

这条不弄清楚，买回来的标签可能一半学生用不了。以下为 2026 年现状（已核实浏览器厂商与苹果官方文档）：

| 设备 / 浏览器 | 网页里能不能读到标签 | 能做什么 | 不能做什么 |
|---|---|---|---|
| **安卓 + Chrome / Edge / 三星浏览器** | ✅ 能（Chrome 89 起） | 读到标签编号（UID）和标签里存的内容 | 必须页面在前台、用户点了按钮才启动；不能后台偷偷读 |
| **iPhone（XS 及以后）** | ❌ **读不到** | 系统级「后台读标签」：碰到含网址的标签会弹一条通知，点开用 Safari 打开那个网址 | 拿不到标签编号；拿不到"我碰的到底是哪枚标签"的凭据 |
| **iPhone（7 / 8 / X）** | ❌ 读不到 | 控制中心加个「NFC 读卡器」手动扫，结果仍是打开网址 | 同上 |
| **微信内置浏览器** | ❌ 读不到 | 无 | 微信屏蔽了这类能力，必须"用系统浏览器打开" |
| **电脑** | ❌ | 无 | 桌面浏览器根本没有这个接口 |

两个数字要记住：**能用网页 NFC 的浏览器占全球约 6%**（基本就是安卓那部分）；**苹果至今没有把 Web NFC 放进 Safari，也没有开关可以打开**——这不是我们没做对，是它就没有。

### 由此定下三条铁律

1. **NFC 是加分项，不是唯一方式。** 系统自动判断：手机支持就显示「碰一碰打卡」，不支持就显示动态码/定位，学生不用自己选，也不会看到"你的手机不支持"这种打脸提示。
2. **iPhone 上的标签只能当"快捷打开"**（省去输网址、省去翻图标），**不能当到场证明**——因为标签里的网址谁都能复制转发。
3. **先数人头再花钱。** 学生里安卓占多少，直接决定这件事值多少。见第九节第 1 条。

## 二、NFC 到底能解决我们什么问题

### 能解决的（这才是它真正的价值）

| 现在的痛点 | NFC 之后 |
|---|---|
| 老师点名 80 人，5–10 分钟，还容易听错记错 | 学生自己排队碰，**每人约 2 秒**，80 人 3 分钟内完事 |
| 人不在教室也能打卡（同学代打、宿舍里打） | **必须人在标签旁边**——这是物理约束，绕不过去 |
| 点完名还要回办公室往系统里录一遍 | 碰完直接进考勤表，**自动进量化**，一步到位 |
| 早功、晚自习也要点一遍 | 同一枚标签，不同时段自动判成不同性质 |

### 解决不了的（别指望它）

- 有人把标签**克隆**一枚带回家（淘宝有"可改编号"的魔改标签，¥5 上下）
- 有人把**账号密码给同学**（这是账号问题，不是 NFC 问题）
- 有人**拿真标签在宿舍用**（除非叠加定位，见第六节）

**所以 NFC 解决的是「效率 + 人在现场」，不是「杜绝作弊」。** 剩下的那点风险用第六节的四层办法管住，成本远低于追求绝对防伪。

## 三、三种贴法，选哪种

| 方案 | 怎么做 | 评价 |
|---|---|---|
| **A. 教室固定标签**（一间教室一枚，贴在门口/讲台） ✅ **推荐** | 学生拿自己的手机去碰这枚标签 | 最省、体验最好。证明"我在这个物理位置"。一枚丢了补一枚 ¥2 |
| B. 学生一人一张卡 | 学生刷自己的卡 | ❌ 不推荐：卡能借给同学，反而更弱；要老师逐个刷 80 张，比点名还慢；80 张卡的管理成本远高于 8 枚贴纸 |
| C. 只当快捷入口 | 门口贴一枚，碰一下打开系统 | 只能当 A 的附赠功能——顺手把网址写进标签，碰一下就打开打卡页，省得找图标 |

**结论：按 A 做，顺带享受 C。**

## 四、完整链路：从贴标签到量化扣分

```
【一次性】教务登记
  贴标签 → 教务端「打卡标签」页 → 读一次 / 手动输编号 → 绑定到「BY08」→ 保存

【每天】学生打卡（安卓）
  打开系统 → 今日页「碰一碰打卡」→ 手机贴近教室标签（2 秒）
      → 读到编号 → 连同"读到那一刻"一起发给服务端
      → 服务端判定 → 返回一句人话："已打卡 · 高二1班 · 第2节 · 正常"

【每天】学生打卡（iPhone）
  打开系统 → 今日页 → 输入老师/教务报的 4 位动态码（或走定位）→ 同样写进考勤表

【自动】
  写入 att:{日期} → 量化自动重算（现有 syncAtt 逻辑，一行不用改）
      → 教务端考勤表每条记录带来源标记：手点 / NFC / 补签，精确到秒
```

### 判定这一步是整套方案的灵魂：和课表联动

系统里已经有**教室**（`rooms`：BY03、BY05…）、**作息**（`periods`：第几节几点到几点）、**课表**（`schedule`：哪天哪节哪个班在哪间教室）。三样凑齐，就能做到一件别的产品做不了的事：

> **学生不用选班级、不用选节次。碰一下，服务端自己知道他是谁、这节课是什么、有没有迟到。**

判定顺序（全部在服务端，用**服务端时间**，改手机时间没用）：

1. 编号 → 查登记表 → 得到教室（查不到 → "这枚标签没登记"，拒绝）
2. 取服务端现在时间
3. 查今天这间教室的课表 → 找到"当前时间点所在的那一节"（课前 15 分钟内也算这一节）
4. 确认这个学生**属于这个班**（不属于 → 记一次"串班"，不写入，教务端能看到）
5. 迟到判定：`现在 ≤ 上课时间` → 正常；`上课 < 现在 ≤ 上课+X 分钟` → 迟到；再晚 → 由教务定"迟到"还是"缺勤"
6. 写 `att:{日期}`，附 `src:'nfc'`、`room`、`nfcId`、精确到秒的时间
7. 量化自动跟上（迟到 −2 之类，沿用现有细则）

早功、晚自习这类**不在课表里**的固定时段，在设置里单独配一个时段（如早功 06:30–07:10，任意教室标签都算），走同一套判定。

## 五、学生实际的操作体验（安卓）

1. 打开系统，今日页最上面就是打卡卡：现在该不该打、这节课是什么
2. 点「碰一碰打卡」→ 屏幕提示"把手机背面（安卓 NFC 天线一般在背面上部）靠近教室标签"
3. 贴近 1–2 秒 → 振动 + 一句结果：**"已打卡 · 高二1班 · 第3节 · 正常"** 或 **"迟到 4 分钟 · 高二1班 · 第3节"**
4. 打完就完事，不用排队等老师，不用报名字

iPhone 上：同一张卡，按钮变成「输入动态码」，其余体验完全一致。

**没网怎么办**：读到标签但发不出去 → 本地存"待传"，联网自动补传。补传**一律按服务端收到时间判迟到**——断网只会更不划算，这条不变。

## 六、防作弊：能做到哪一步，剩下那点怎么管

### 四层，从外到内

| 层 | 挡住什么 | 挡不住什么 |
|---|---|---|
| ① **物理到场**：必须碰到教室那枚标签 | 宿舍打卡、同学代打 | 有人克隆标签带走 |
| ② **时间窗 + 课表匹配**：只在这节课前后 X 分钟开放，且这间教室此刻确实有这个班的课 | 提前一天打、跑到别的教室打、非上课时段瞎打 | 克隆者在正确时间窗里打 |
| ③ **账号登录**：必须本人账号（60 天免登，换设备要重登） | 借别人手机打（那还得知道密码） | 把密码告诉同学 |
| ④ **异常看得见**：教务端能看每条记录的来源与精确秒数，异常单独列出来 | 让想钻空子的人知道"老师看得见" | — |

### 关于"标签被克隆"，我把话说透

- 普通 NTAG213 标签的编号**可以被改写复制**（淘宝"UID 可改"魔改标签，需要专用设备写入）。这是真实存在的风险。
- 但克隆者**每次都得先到教室碰一次真标签**——如果我们让标签里的内容**每周/每天换一次**（教务拿安卓手机碰一下重写，几秒钟），克隆的标签下次就失效，他必须每周亲自来一趟。而每周都亲自来了，打卡也就没必要作弊了。
- **这个逻辑是关键**：滚动周期越短，克隆的收益越低，最后归零。

### 终极方案（先不做，留好接口）

用 **NTAG 424 DNA** 芯片 + SDM（每次被读，标签吐出一个带滚动计数器和加密签名的网址，服务端验签）。这样：
- 克隆编号没用（签名需要密钥）
- 复制网址没用（计数器回退会被发现）
- **安卓和 iPhone 都能防伪**（iPhone 打开的网址里就带着签名参数，服务端照样验）

代价：标签 ¥10–20/枚（贵 10 倍），且需要一次性烧录配置（得借个 USB 读卡器或让商家代配）。
**建议**：软件上先把验签函数的位置留好，先用便宜标签跑通流程，等真有人钻空子了再换芯片——换标签不用改代码。

## 七、教务端要新增什么

**新页面「打卡标签」**（教务可见，老师端和学生端都看不到）

- 列表：标签别名（直接用教室名）· 编号 · 绑定教室 · 状态 · 最近一次使用
- 添加：安卓手机上点「读新标签」→ 碰一下 → 编号自动填好 → 选教室 → 保存
  - **教务自己用 iPhone 怎么办**：让商家把编号**印在标签表面**（定制印刷几乎不加钱），肉眼看到输进去就行，一次性 8 枚的事
- 停用/启用：标签掉了、换了教室，停用旧的，别删（留着查历史）
- 重写：安卓手机上可以给某枚标签换一次内容（配合第六节的滚动策略）

**考勤页的变化**

- 每条记录旁边一个小标记：手点 / NFC / 补签
- 点开看精确时间（到秒）
- 新增「异常」筛选：串班、非时段、同一标签短时间多人
- 一键改判（改成"未到"→ 量化自动重算，现有能力）

**设置页「打卡规则」**

- 课前几分钟开放（默认 15）
- 迟到界限几分钟（默认 0，即上课铃响即为迟到）
- 超过几分钟算缺勤（默认不启用，教务手工判）
- 早功 / 晚自习固定时段（不走课表）

## 八、采购清单（可以直接发给淘宝客服）

> 数量按 8 间教室估算，您按实际教室数改。

| 项 | 规格 | 数量 | 单价 | 小计 |
|---|---|---|---|---|
| NFC 贴纸 | **NTAG213**（或 215），直径 ≥25mm，不干胶 | 18 枚（8 教室 ×2 备用 + 2 测试） | ¥1–2 | ¥20–35 |
| 抗金属款（如果贴在金属门框上） | NTAG213 + 抗金属层，滴胶/硬片 | 同上 | ¥3–6 | ¥55–110 |
| 定制印刷 | 表面印教室名 + 编号（或二维码） | 一次性 | 约 ¥0.5/枚 或 版费 ¥30 | ¥30 上下 |
| 预写内容 | 让商家把每枚写成 `https://liyun2026.top/?tag=BY08-7F3C`（每枚后缀不同） | — | 多半免费 | ¥0 |

**合计：¥50–150，一次性。服务费仍然是 ¥0。**

### 几句务必交代商家的

1. **芯片要 NTAG213/215/216，不要 MIFARE Classic**（iPhone 读不了 Classic）
2. **贴在金属门框上必须买"抗金属"款**，普通贴纸贴金属会失谐读不出来
3. **表面要印编号**（或印二维码＝编号），登记时肉眼可见，教务不必依赖安卓手机
4. 每枚预写不同的网址后缀（若商家不愿定制，就留空，我们自己写）

### 粘贴位置（很影响成功率）

- 高度 **1.0–1.3 米**，顺手；竖面（门框内侧、讲台侧板、玻璃、乳胶漆墙）
- **避开金属、避开大块电池/电机**；金属门框要么换抗金属款，要么贴旁边玻璃上
- 安卓天线多在**背面上部**，iPhone 在**手机顶部**——贴竖面比贴桌面好碰得多
- 贴完**先拿安卓和 iPhone 各试一次**，确认能读再固定

## 九、落地节奏

| 阶段 | 做什么 | 验收标准 |
|---|---|---|
| **0. 数人头**（半天，不花钱） | 在学生群接龙："安卓 / iPhone"，或在班主任处问 | 安卓占比 ≥50% 才值得铺开；<30% 建议只做一间教室试点 |
| **1. 试点一间教室**（1–2 周） | 买 3 枚标签，选一间最常用的教室；打通登记→打卡→考勤→量化全链路 | 安卓学生碰一下 2 秒内出结果；考勤表自动出现记录并带来源标记；量化自动扣分 |
| **2. 铺开**（1 周） | 全部教室贴标签，配好早功/晚自习时段 | 连续一周无人工补录 |
| **3. 可选升级** | 若真出现克隆作弊，换 NTAG 424 DNA | 验签通过率 100%，异常打卡归零 |

**建议顺序**：先做阶段 0 和 1，花几十块钱验证，别一次买齐。

## 十一、需要您拍板的五件事

1. **学生里安卓占多少？** —— 决定这件事值不值、铺不铺开。这是唯一的先决条件。
2. **教室几间？门框是不是金属的？** —— 决定买普通款还是抗金属款、买多少。
3. **您（或登记这件事的人）用 iPhone 还是安卓？** —— 决定标签编号怎么录入（印在表面 / 借安卓机读一次）。
4. **打卡时间窗**：默认「课前 15 分钟开放，上课铃响即算迟到」，要不要放宽？早功/晚自习的固定时段是几点到几点？
5. **先试点一间教室，还是一次铺开？** —— 我建议试点。

> 补充：这条会并入 `学生端综合方案-v2.md` 第八节的待决事项第 1 条（打卡防作弊档位），届时的口径是：**动态码为主、NFC 为辅（安卓）、定位兜底**。NFC 不取代动态码，而是给安卓学生一条更快的路。
