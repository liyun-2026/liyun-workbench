## 0. 铁律

1. **生产系统绝对只读**：`砺蕴工作台/index.html` 只许读，禁止任何修改。
2. **手机端一律不写**：本预览是纯桌面版（min-width 1200 固定布局），不写任何 @media 手机适配、不碰生产端手机样式。
3. **不编造功能**：每页的模块、字段、按钮、文案必须以《01-页面清单》提取的生产系统真实结构为准；示例数据可以造（合理、符合业务），**结构和功能名不能造**。
4. 页面文件放 `docs/preview-2026-10/`，命名 `page-<id>.html`；总览入口 `index.html`（34 页卡片网格，每卡带页面名 + 缩略说明 + 链接）。

## 2. 页面骨架（34 页统一）

每页 = 门户条 + 校名头 + 校色导航条 + 内容区 + 页脚，全部照抄 G4 的结构：

- **门户条**（34px，--blue-deep）：左「学生端/教职工」，右「返回总览」。❌ 家长端/门户/邮箱/帮助均无此设计，不出现；学期条亦无「校历」
- **校名头**（88px 白底）：蓝章 logo（`redesign-fresh/assets/seal-boyi.png`，58px）+ 「砺蕴教务系统」宋体 27px + 英文小字；右侧搜索圆钮 + 用户「齐活林 · 交付总监 · 全部权限」（学生端页面换成对应学生身份）
- **导航条**（--blue 渐变）：生产系统 NAV_ORDER 的真实页面为导航项（导航高亮当前页，金色下划线）；**不要用 G4 mock 里那套假导航名**，以《01-页面清单》为准
- **内容区**：max-width 1280，padding 46px 40px；卡片 = 白底 / 1px --line / radius 6 / 无重阴影
- **章节标题**：宋体 24px + 右侧英文小字 + `.rule` 蓝金分隔线（蓝 120px 渐变到 --line）
- **页脚**：深蓝 --blue-ink 三栏 + 版权条（照抄 G4）

## 3. 组件词汇表（全站复用，每页从中取用）

| 组件 | 规格 |

| 通知条目 | 日期框（宋体 23px 蓝 + 年月小字）+ 标题 + 摘要，虚线分隔，hover 淡蓝底 |
| 数据卡 | 白卡，宋体/Georgia 大数字 34px 蓝（热点金），标签 11.5px letter-spacing 3px |
| 表格 | 白卡内，表头 12px --ink-2 字距 2px，行 44px，虚线行分隔，状态用胶囊 |
| 状态胶囊 | 进行中=蓝底白字 / 待办=金边金字 / 正常=灰边 / 异常=红字红边（#c0392b） |
| 表单控件 | 输入框白底 1px --line radius 4 focus 蓝；按钮：主=--blue 白字，次=白底蓝字蓝边，危险=红 |
| 时间轴 | 左金线 + 金节点（当前页金实心+光圈），条目参考 G4 今日课表卡 |
| 空状态 | 居中：线性插图占位（方形虚线框 + 「暂无数据」宋体）+ 说明 + 主按钮 |
| 弹窗/抽屉 | 预览里静态摆一个示例即可（半透明遮罩 + 白卡 radius 8） |

| 入场动画 | 每页顶部区块 .au fadeUp 错峰（d1~d6，照抄 G4），全站克制不加花活 |

## 4. 各页要点（结构以《01-页面清单》为准，此处只定调性）

- **教务端 22 页**：信息密度正常偏工作台；today/home 用大数字+时间轴；表格页（考勤/记录/花名册/学员/教师/作业/考试/量化/晚会/合作/工单/制度）统一表格组件；timetable 课表页沿用生产格子概念但用新令牌重绘；settings/profile 表单组件。
- **学生端 10 页**：同套令牌，身份换学生（头像「陈」示例），页面顶部多一条「我的班级 · 第 9 教学周」上下文条；语气亲和但same骨架。
- 每页底部不需要 G4 首页那种轮播/快捷图标行（那是门户页专属，只存在于 page-home 若生产系统有对应模块）。

## 5. 验收标准

1. `docs/preview-2026-10/index.html` 能一屏看全 34 页入口且全部链接可达；
2. 每页模块名与生产系统一致（对照清单），无自创功能；
3. 全站只出现第 1 节的令牌色，无 rogue 颜色；
4. 桌面 1440 宽打开无横向滚动、无手机样式；
5. grep 全部 page-*.html 不出现 `@media (max-width`。
