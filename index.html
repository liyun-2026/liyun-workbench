上课日
每个上课日上什么（一行 = 一节课；一格放几个班就写「BY05/BY06」）

「生成」只补空格子，不动你已经排好的课；「清空该区间后重排」会先把这段时间的旧课表存进「往期课表」，再整段重排。

🗓️ 大课表 （点格子直接排 / 改）

多班同室共上的「合练」课（如科学发声、普通话发声一起练功），在格子里勾选「合练」后不再提示撞课。

左列是节次 / 时间，上排是日期 + 星期。一格可放多个班；点格子里已有的课节、或右下角「＋」直接编辑、删除。

🎓 小课 （一对一 / 辅导课，独立于大课表）

不选节次、单独填时间也行

📥 导入课表文字 （本机解析，不联网、不花钱）

拍课表照片 / 传图片、txt、docx，识别出来核对一遍再解析

能认出来什么（点开看）

解析完全在本机跑，不上传、不花钱。能认：日期（7月10日 / 7-10 / 2026-07-10）、时间（08:00-09:40）、班级（BY05 或名册里的班名）、教室（方括号里的 BY08）、老师姓名（自动匹配教师档案）。
认不准也没关系 —— 解析结果会先进一张可以逐格修改的表，你核对完再点导入。

导入是整表替换：现有课表会先自动存进「往期课表」。若只是想补几节，直接在「大课表」里点格子加，或去上面的「排课台」整段重排。

💾 数据备份

你的所有数据都存在这台设备的浏览器里，同时会同步到你自己开启的云端。
换手机、清理浏览器数据前，记得先导出备份。
备份 = 导出：把数据存成一个文件（存到「文件」或发微信）； 恢复：换设备或数据丢了后，选中之前导出的那个文件。没导出过，就没有可恢复的文件。
